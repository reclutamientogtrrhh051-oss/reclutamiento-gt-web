# RECLUTAMIENTO GT RRHH

Sitio web oficial para promocionar servicios de Recursos Humanos, evaluaciones y asesoría legal.

## Publicación con GitHub Pages

1. En el repositorio, entrar a **Settings → Pages**.
2. En **Build and deployment**, seleccionar **Deploy from a branch**.
3. Seleccionar la rama **main** y carpeta **/ (root)**.
4. Guardar.

El sitio utiliza `index.html`, `style.css` y `script.js`, sin dependencias externas.
